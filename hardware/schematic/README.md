# Schematic and perfboard drawings (CADCraft)

`schematic.scr`, `perfboard-layout.scr` and `perfboard-solder-side.scr` are CADCraft
scripts (one `id {json}` command per line, `;` starts a comment), generated by
`gen/gen_schematic.py`, `gen/gen_perfboard.py` and `gen/gen_solder_side.py`
(hardware rev C: LiPo + TP4056 + INMP441 I2S microphone).

- `schematic.*` — circuit per [../DESIGN.md](../DESIGN.md) sections 1–4.
- `perfboard-layout.*` — 70 × 50 mm perfboard, **component side**: hole grid A..X × 1..18,
  mounting holes, every part body with its leads in named holes, parts table. No wires.
- `perfboard-solder-side.*` — the same board **mirrored** (seen from the solder side,
  column X on the left): all links, the JP1 solder bridge and the 22 insulated wires
  with their number, net and colour, plus the wiring legend.

The two perfboard generators read **`../layout/layout.json`** (made by
`../layout/gen_layout.py`), the single source of truth for every lead and wire;
they contain no hand-typed coordinates. Rerun them after changing the layout:

```sh
python3 gen/gen_schematic.py    > schematic.scr
python3 gen/gen_perfboard.py    > perfboard-layout.scr          # [path/to/layout.json] optional
python3 gen/gen_solder_side.py  > perfboard-solder-side.scr
```

Replay on the Windows host from WSL (`CLI="/mnt/c/Program Files/CADCraft/cadcraft-cli.exe"`,
`W` = the folder holding the `.scr` as a Windows path, e.g. `C:\Users\daniele\esp-button-cad\schematic`,
`WF` = the same path with forward slashes, which JSON needs):

```sh
# 1. DXF + PNG (2400 × 1600, dark background) from the script
"$CLI" run --metric --script-file "$W\schematic.scr" --save "$W\schematic.dxf" --export "$W\schematic.png"

# 2. SVG (white background) from the DXF
"$CLI" convert "$W\schematic.dxf" "$W\schematic.svg"

# 3. Monochrome PDF from the DXF (A3 for the schematic, A4 for the two perfboard sheets)
"$CLI" run "$W\schematic.dxf" --cmd 'exportpdf {"path":"'"$WF"'/schematic.pdf","layout":"Model","paper":"A3","landscape":true,"fit":true,"lineweights":true,"plotStyleTable":"monochrome.ctb"}'
```

Run the same three commands with `perfboard-layout` and `perfboard-solder-side`
in place of `schematic` (and `"paper":"A4"` for their PDFs).

Files: `schematic.{scr,dxf,svg,png,pdf}`, `perfboard-layout.{scr,dxf,svg,png,pdf}`,
`perfboard-solder-side.{scr,dxf,svg,png,pdf}`.
The bill of materials and the netlist are in [../BOM.md](../BOM.md), the assembly
steps in [../BUILD.md](../BUILD.md).
